Rondel

Retrospectives and team meetings: write, group, vote, discuss and agree actions in a retro, or run a meeting with an agenda, timer, shared notes, decisions and action items. Prepare before it starts, and repeat it weekly or monthly from one link.

Everything people write is encrypted in the browser with a key that lives only in the meeting link, so the server cannot read it. No accounts. Open source under Apache-2.0: github.com/spikinglabs/rondel.
